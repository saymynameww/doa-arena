# 算法忠实性初步代码审计

## 完成内容

按需求方确认，将忠实呈现已声明算法及计算成本写入 AGENTS.md 和项目总览 v1.3。本轮检查全部五个内置插件、arena_api.kit 和 runner 计时边界。未改算法、默认值和历史结果。

## 怎么验收

核对 core/algorithms 下的 CBF、MVDR、MUSIC、RootMUSIC、ESPRIT 及 arena_api/kit.py；runner/core.py 中 configure/load 与 estimate 的计时边界。

## 检查结果

- CBF：Bartlett 谱、阵列导向矢量范数归一化、谱最大值归一化，默认固定网格与 top_k 取峰。取峰与已知 K 是评测协议的一部分。
- MVDR：默认对角加载为 0，默认不细化；矩阵秩不足时自动 pinv，正常情况 inv，info 记录 used_pinv。伪逆回退属于待明确标识的数值分支，不能据此声称完全复现原始可逆协方差公式。
- MUSIC：噪声子空间谱，默认无平滑、无细化；平滑、抛物线、局部加密可显式选择。有限固定网格是已声明的离散实现，不等于连续谱精确最大化。
- Root-MUSIC：噪声子空间多项式、取单位圆内最接近单位圆的 K 个根、角度映射；默认不平滑。严格圆内判定、不可实现角度过滤、根不足等数值边界仍需与选定参考文献逐项核对。
- ESPRIT：默认 TLS，也支持显式 LS，默认不平滑；旋转不变子阵求解。界面插件名称仍为 ESPRIT，默认 TLS 方法应更醒目地标识；不可实现角度被过滤。
- 公共峰检索只取严格内部局部极大值，不接收端点和平顶峰；谱分母设浮点下限。这些实现选择需要纳入忠实性复核。
- estimate 计时不含 load/configure/预热；固定网格导向矩阵在 configure 中预计算，局部加密导向矢量在 estimate 中计算。当前运行时间不能称为算法完整端到端成本。

## 已知问题与建议

建立算法—参考来源—公式—数值选择—默认变体—失败策略—计时边界追踪表，再逐项做独立数值验证。数值稳定实现不一概视为违规；关键是忠实、公开并可辨识。本轮为静态审计和文档更新，没有运行新的数值实验；已有测试通过不能替代文献忠实性证明。
