## 3. 怎么验收

### 3.1 启动服务

**前提**：Node.js 已安装（v16+）

**后端**：
```bash
python -m arena.server.cli
```

**前端**：
```bash
cd frontend
npm install  # 首次运行
npm run dev
```

访问：http://localhost:3000

### 3.2 验收流程

#### 流程 1：配置实验（核心功能）

1. **打开主页**
   - 看到左右分栏布局
   - 左侧配置表单，右侧预览和摘要

2. **实验方式**
   - 三张卡片展示
   - 点击切换，查看高亮效果
   - 选择"参数扫描"

3. **扫描配置**
   - 出现灰色背景的扫描配置卡片
   - 选择扫描变量（如 SNR）
   - 输入扫描范围，查看实时显示的取值数量

4. **场景配置**
   - 展开场景折叠面板
   - 修改阵元数，观察预览图变化
   - 修改快拍数，查看校验提示

5. **添加算法**
   - 点击"添加算法"下拉菜单
   - 选择 MUSIC 和 ESPRIT
   - 查看算法卡片：
     - 色块（●/■ 符号和颜色）
     - 可编辑显示名
     - 参数摘要行
   - 点击展开按钮，查看参数表单
   - 修改参数，观察摘要更新
   - 点击复制按钮，生成副本

6. **即时校验**
   - 清空算法列表，查看红色错误提示
   - 设置快拍数为 5，查看黄色警告
   - 修复后警告消失

7. **右侧预览**
   - 场景预览：半圆刻度、阵元、信源方向
   - 配置摘要：关键信息和预估次数

8. **导出配置**
   - 点击"导出 JSON"，下载配置文件

9. **运行实验**
   - 点击"运行实验"
   - 自动跳转到运行页

#### 流程 2：运行和查看结果

1. **实时进度**
   - 任务状态卡片
   - 进度条实时更新
   - 当前试验数显示

2. **完成后**
   - 显示绿色成功提示
   - 显示图表区域（3 个标签页）
   - 点击"导出"下拉菜单
     - 数据格式组
     - 图表格式组
     - LaTeX 和脚本

3. **查看图表**
   - 切换标签页（RMSE/成功率/时间）
   - Plotly 交互：缩放、悬停、下载

#### 流程 3：其他页面

1. **历史实验**
   - 点击左侧"历史实验"
   - 使用状态筛选器
   - 搜索任务 ID
   - 观察实时过滤

2. **实验对比**
   - 点击左侧"实验对比"
   - 添加多个实验
   - 查看多曲线叠加对比图

3. **模板管理**
   - 点击左侧"模板"
   - 查看模板列表
   - 点击"删除"，确认对话框

4. **设置**
   - 点击左侧"设置"
   - 查看所有设置项
   - 修改并保存

## 6. 已知问题

### 6.1 图表数据为模拟数据

**问题**：ResultCharts 组件使用硬编码的模拟数据。

**原因**：后端 API 未返回图表数据格式。

**影响**：图表展示正常，但数据不真实。

**解决**：后端实现图表数据 API 后替换。

### 6.2 导出功能未连接后端

**问题**：ExportMenu 的导出操作未调用后端 API。

**原因**：后端导出 API 未实现。

**影响**：点击导出后无实际文件。

**解决**：连接后端导出 API。

### 6.3 模板功能为静态数据

**问题**：模板页使用硬编码模板。

**原因**：后端模板 API 未实现。

**影响**：模板 CRUD 不持久化。

**解决**：实现后端模板存储。
