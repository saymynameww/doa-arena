## 2. 怎么验收

### 2.1 安装依赖

```bash
cd frontend
npm install
```

### 2.2 启动开发服务器

**前提**：后端服务已运行在 `http://127.0.0.1:8765`

```bash
npm run dev
```

访问：http://localhost:3000

### 2.3 验收流程

#### 1. 主页（实验配置）

- 填写实验名称
- 选择实验类型（蒙特卡洛）
- 设置试验次数（如 50）
- 配置场景参数
- 添加算法（如 MUSIC、ESPRIT）
- 点击"运行实验"

#### 2. 实验运行页

- 自动跳转到运行页
- 观察实时进度更新
- 查看进度百分比
- 等待实验完成

#### 3. 历史实验页

- 点击左侧"历史实验"
- 查看任务列表
- 点击"查看"进入详情

#### 4. 算法库页

- 点击左侧"算法库"
- 浏览算法列表
- 查看算法参数

## 5. 与设计文档的偏离

### 5.1 简化的参数表单

**设计**：参数表单由后端 JSON Schema 自动生成。

**实际**：当前使用简化的静态表单。

**影响**：核心流程可用，完整的动态表单后续实现。

### 5.2 缺少图表展示

**设计**：结果页包含 Plotly 交互式图表。

**实际**：当前未实现图表展示。

**影响**：结果查看功能不完整。

### 5.3 简化的页面

**设计**：完整的 8 个页面。

**实际**：实现了 4 个核心页面。

**影响**：基本功能可用，高级功能待补充。
