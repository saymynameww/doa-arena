## 1. 完成内容

按架构文档第 12.2 节 M2 范围，逐项对照：

### ✅ 1.1 四类误差插件

- ✅ 位置误差 (`position`)
- ✅ 幅相误差 (`gain_phase`)
- ✅ 互耦误差 (`mutual_coupling`)
- ✅ 阵元故障 (`element_failure`)

详见 Phase 1 提交（`v0.1.0-m2p1`）。

### ✅ 1.2 配置模型

- ✅ `ScenarioConfig`：场景配置（阵列、信源、误差、快拍数）
- ✅ `ExperimentConfig`：实验配置
  - 支持 single/monte_carlo/sweep 三种类型
  - 算法列表配置
  - 实验选项（并行、公共随机数、预热等）
- ✅ `AlgorithmConfig`：算法实例配置
- ✅ `SweepConfig`：参数扫描配置
- ✅ Pydantic 模型，自动校验

**简化说明**：当前为简化版本，包含核心字段。完整版本（包含所有扫描路径、完整的角度配置等）将在后续补充，但不影响 M2 核心功能验收。

### ✅ 1.3 场景生成器增强

- ✅ 整合误差功能
  - 四个阶段：positions → manifold → signal → output
  - 固定/每次随机误差实现
  - `ImpairmentInstance` 数据结构
- ✅ 与 M1 的场景生成器向后兼容

### ✅ 1.4 实验运行器 (Runner)

- ✅ **单次试验执行** (`run_trial`)
  - 场景生成 → 算法估计 → 结果收集
  - 异常隔离（单个算法出错不影响其他）
  - 自动计时（毫秒级）
  
- ✅ **完整实验流程** (`run_experiment`)
  - 三种实验类型：single/monte_carlo/sweep
  - 算法加载与配置
  - 预热机制（CUDA初始化等一次性开销）
  - 随机数管理（公共随机数/独立随机数）
  - 扫描点迭代
  
- ✅ **结果数据结构**
  - `TrialResult`：单次试验结果
  - `SweepPointResult`：扫描点结果
  - `ExperimentResult`：完整实验结果

### ✅ 1.5 结果存储

- ✅ **原子写入** (`ResultWriter`)
  - 临时文件 + 重命名（架构 5.8 节）
  - Windows 文件锁定处理
  
- ✅ **文件格式**
  - `config.json`：实验配置
  - `meta.json`：元信息（开始时间、耗时等）
  - `results.npz`：逐次试验结果
    - 估计角度、计时、失败标记
    - 按算法组织
  - `summary.json`：汇总统计
    - 每个扫描点的指标
    - RMSE、成功率等

### ✅ 1.6 脚本门面 API

- ✅ `arena.run_experiment(config)`：运行实验
- ✅ 顶层导出配置类
- ✅ 简洁的 Python API

### ⏳ 1.7 未完成功能（M2范围外或待后续补充）

- ⏳ 插件注册与外部发现（架构 10 章）
- ⏳ 版本采集
- ⏳ 并行执行（`workers > 1`，预留接口）
- ⏳ 取消机制
- ⏳ 工作目录结构（完整的目录管理）
- ⏳ 索引（SQLite，Web 服务用）
- ⏳ `arena run` 命令行工具

**说明**：这些功能大部分是 Web 服务相关或高级特性。M2 核心目标"脚本模式可用"已达成，未完成部分不影响基本使用。

### 2.3 验收重点（架构 12 章）

#### ✅ 验收点 1：脚本模式运行实验

创建测试脚本 `test_m2.py`：

```python
from arena import ExperimentConfig, AlgorithmConfig, run_experiment
from pathlib import Path

# 配置实验
config = ExperimentConfig(
    name="M2 验收测试",
    trials=20,
    algorithms=[
        AlgorithmConfig(id="music", label="MUSIC"),
        AlgorithmConfig(id="esprit", label="ESPRIT"),
    ],
)

# 运行实验
result = run_experiment(config)

# 写入结果
from arena.core.storage import ResultWriter
writer = ResultWriter(Path("output"))
writer.write_experiment(result)

print(f"实验完成！")
print(f"- 扫描点数: {len(result.points)}")
print(f"- 试验数: {len(result.points[0].trials)}")
print(f"- 算法数: {len(result.points[0].trials[0].estimates)}")
```

运行：
```bash
python test_m2.py
```

**预期结果**：
- 成功运行，无异常
- 输出目录包含 4 个文件：config.json, meta.json, results.npz, summary.json

#### ✅ 验收点 2：参数扫描

```python
from arena import ExperimentConfig, AlgorithmConfig, run_experiment
from arena.core.config import SweepConfig

config = ExperimentConfig(
    name="SNR 扫描",
    trials=50,
    algorithms=[AlgorithmConfig(id="music")],
    sweep=SweepConfig(
        path="scenario.sources.snr_db",
        values=[0, 5, 10, 15, 20],
        label="SNR",
        unit="dB",
    ),
)

result = run_experiment(config)

print(f"扫描点数: {len(result.points)}")
for point in result.points:
    print(f"SNR = {point.sweep_value} dB: {len(point.trials)} 次试验")
```

**预期结果**：
- 5 个扫描点
- 每个点 50 次试验

#### ✅ 验收点 3：随机数可复现性

```python
from arena import ExperimentConfig, AlgorithmConfig, run_experiment

config = ExperimentConfig(
    name="可复现性测试",
    trials=10,
    algorithms=[AlgorithmConfig(id="music")],
)

# 运行两次，相同种子
result1 = run_experiment(config)
result2 = run_experiment(config)

# 比较结果
import numpy as np

est1 = result1.points[0].trials[0].estimates["music"].angles
est2 = result2.points[0].trials[0].estimates["music"].angles

print(f"结果一致: {np.allclose(est1, est2)}")
```

**预期结果**：`结果一致: True`

## 4. 与设计文档的偏离

### 4.1 简化的配置模型

**设计**：完整的配置模型包含所有字段（架构文档第 3 章）。

**实际**：实现了简化版本，包含核心字段：
- 场景配置：阵列、信源、误差、快拍数
- 实验配置：类型、算法、扫描、选项

**影响**：不影响 M2 验收，完整版将在 M3/M4 前补充（Web 服务需要完整 Schema）。

### 4.2 未实现的高级功能

**设计**：M2 包含插件注册、版本采集、并行执行、取消机制（架构 12.2 节）。

**实际**：这些功能预留接口但未实现：
- 插件注册：内置算法硬编码，外部算法将在后续支持
- 版本采集：未实现（M4 Web 服务时需要）
- 并行执行：预留 `workers` 参数，但当前只支持串行
- 取消机制：未实现（M4 Web 服务时需要）

**影响**：不影响脚本模式使用，这些是 Web 服务相关功能。

### 4.3 工作目录结构

**设计**：完整的工作目录结构（数据格式规范第 2 章）。

**实际**：只实现了结果写入，未实现：
- 实验 ID 生成
- 目录结构管理（`experiments/<ID>/`）
- 索引（SQLite）

**影响**：当前结果写入到指定目录，完整目录管理在 M4 实现。
