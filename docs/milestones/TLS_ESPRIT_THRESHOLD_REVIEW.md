# TLS-ESPRIT 验收门限复核（已批准）

日期：2026-11-16。状态：需求方已批准仅修订规定场景的门限，算法保留。

## 1. 完成内容

复核接口规范 13.3 的 TLS 求解与 13.4 的 CRB 效率验收。
生产实现对 `[E1, E2]` 做 SVD，再取右奇异子空间求 TLS 解。
独立复核脚本对增广矩阵的 Gram 矩阵做特征分解，以线性方程求旋转矩阵，
没有调用生产实现求参考角度；最后再与生产实现逐次比较。
8,000 次比较的最大角度差为 `2.859934511434403e-13` 度。

CRB 已使用架构 5.7 的随机信号完整矩阵公式，并通过单信源闭式公式校验。
未用提高 CRB、平滑、加权或替换算法的方式降低效率比。

## 2. 怎么验收

在仓库根目录的开发环境中运行：

```powershell
python scripts/audit_esprit_efficiency.py
python -m pytest tests/unit/core/test_acceptance.py -k efficiency -v
```

第一条输出四个 SNR、四组固定种子各 500 次的数值和两种实现的最大差。
第二条按已批准的分算法门限执行：Root-MUSIC `< 1.5`、TLS-ESPRIT `< 2.0`，不跳过、不标记预期失败。

## 3. 测试结果

场景：M=16、d=0.5λ、K=2、角度 ±10°、N=500、独立复高斯信源、噪声功率 1。
指标为全部试验与全部信源误差平方平均后开方，除以 CRB 方差均值的平方根。

| SNR / dB | 种子 0–499 | 500–999 | 1000–1499 | 1500–1999 |
|---|---:|---:|---:|---:|
| 0 | 1.83710 | 1.79824 | 1.89828 | 1.82949 |
| 10 | 1.82167 | 1.78661 | 1.88050 | 1.81815 |
| 20 | 1.81971 | 1.78574 | 1.87800 | 1.81751 |
| 30 | 1.81938 | 1.78573 | 1.87748 | 1.81759 |

原验收种子 0–499 下 Root-MUSIC 的对应效率比分别为
10 dB：1.01516；20 dB：1.01467；30 dB：1.01455。

## 4. 与设计文档的偏离

TLS-ESPRIT 未达到原 v0.5 的效率比 `< 1.5`。需求方于 2026-11-16 明确批准本报告的修订建议，接口规范已更新为 v0.6，并同步更新测试门限。
本项通过不代表 M1 或 M5 的其他要求已完成验收。

## 5. 需要需求方决定的问题

建议将该固定场景下的门限拆开：Root-MUSIC 继续 `< 1.5`，
未加权 TLS-ESPRIT 改为 `< 2.0`，同时保留符号、双信源精度及独立实现一致性校验。
2.0 是根据四组固定种子的观测范围提出的工程验收值，不是理论效率上界。
需求方已明确回复“批准此门限修订”。授权仅覆盖此处的固定场景与门限；不改变算法公式，不放宽其他测试。

备选：保留 1.5 并继续将该项记为未通过，另行开展理论效率分析。
不建议在本次验收中更换为加权或优化的 ESPRIT，这会改变既定对比基线。

## 6. 已知问题与建议

两条等价求解路径的一致性降低了实现错误的可能，但不能独立证明完整理论效率。
四组数值试验也不构成所有种子、信源间隔和阵元数下的保证。
本建议仅覆盖规范给定场景，不推广为其他配置下的通用门限。
