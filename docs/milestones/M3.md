#### ✅ 验收点 1：图表生成

创建测试脚本 `test_m3_charts.py`：

```python
from arena import ExperimentConfig, AlgorithmConfig, ExperimentType, run_experiment
from arena.core.config import SweepConfig
from arena.core.figures import ChartGenerator

# 运行扫描实验
config = ExperimentConfig(
    name="M3 图表测试",
    type=ExperimentType.SWEEP,
    trials=50,
    algorithms=[
        AlgorithmConfig(id="music", label="MUSIC"),
        AlgorithmConfig(id="esprit", label="ESPRIT"),
    ],
    sweep=SweepConfig(
        path="scenario.sources.snr_db",
        values=[0, 5, 10, 15, 20],
        label="SNR",
        unit="dB",
    ),
)

result = run_experiment(config)

# 生成图表
gen = ChartGenerator(result)
charts = gen.create_all_charts()

print(f"生成图表数: {len(charts)}")
for name in charts.keys():
    print(f"- {name}")
```

## 4. 与设计文档的偏离

### 4.1 Kaleido 依赖

**设计**：静态图导出需要 Kaleido（架构风险 R1）。

**实际**：Kaleido 在 Windows 上运行正常，但作为可选依赖：
- HTML 导出完全可用（无需 kaleido）
- PNG/PDF/SVG 导出需要 kaleido
- 缺少 kaleido 时给出清晰提示

**影响**：HTML 导出已足够大部分使用场景，静态图导出是增强功能。

### 4.2 简化的图表类型

**设计**：M3 可能包含更多图表类型。

**实际**：实现了 4 种核心图表：
- RMSE 曲线
- 成功率曲线
- 计算时间曲线
- 估计散点图

**影响**：覆盖主要使用场景，更多图表可在后续补充。

## 5. 需要需求方决定的问题

### 5.1 Kaleido 是否必须

**问题**：是否要求用户必须安装 kaleido？

**当前方案**：作为可选依赖，HTML 导出作为默认方案。

**建议**：维持当前方案，原因：
1. HTML 导出已满足大部分需求
2. kaleido 安装可能有问题（部分环境）
3. 用户可根据需要选择安装

### 5.2 默认图表样式

**问题**：当前使用 `plotly_white` 主题，是否需要更多样式选项？

**建议**：当前样式已足够清晰，更多样式可在 P2 实现。
