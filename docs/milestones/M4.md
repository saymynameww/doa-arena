import requests

# 提交实验
config = {
    "name": "API 测试",
    "trials": 100,

response = requests.post(
    "http://127.0.0.1:8765/api/experiments/run",

#### 实时进度（SSE）

```python
import httpx

# 订阅进度
async with httpx.AsyncClient() as client:
    async with client.stream(
        "GET",
        f"http://127.0.0.1:8765/api/experiments/tasks/{task_id}/progress"
    ) as response:
        async for line in response.aiter_lines():
            if line.startswith("data:"):
                data = json.loads(line[5:])
                print(f"进度: {data['progress']['percent']}%")
```

## 4. 与设计文档的偏离

### 4.1 简化的子进程隔离

**设计**：实验在独立子进程中运行。

**实际**：当前在线程池中执行。

**影响**：
- 优点：实现简单，性能开销小
- 缺点：算法崩溃可能影响服务
- 后续可升级为子进程

### 4.2 无数据库索引

**设计**：使用 SQLite 索引实验结果。

**实际**：任务状态在内存中，结果在文件系统。

**影响**：服务重启后任务状态丢失，但结果文件保留。

## 5. 已知问题
