**实验管理**：

## 2. 怎么验收

### 2.1 安装依赖

```bash
pip install fastapi uvicorn
pip install httpx  # 测试用
```

### 2.2 启动服务

```bash
python -m arena.server.cli
```

访问：http://127.0.0.1:8765/api/health

### 2.3 测试 API

```python
import requests

# 提交实验
config = {
    "name": "API 测试",
    "trials": 10,
    "algorithms": [{"id": "music"}],
}

response = requests.post(
    "http://127.0.0.1:8765/api/experiments/run",
    json=config,
)

task_id = response.json()["task_id"]

# 查询状态
response = requests.get(
    f"http://127.0.0.1:8765/api/experiments/tasks/{task_id}"
)

print(response.json())
```
