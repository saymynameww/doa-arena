## 待确认：内置 doa-basic 1.0 参数

总览第 14 节将标准场景的具体配置列为待定。以下是工程比较基准，不作为算法理论性能保证。

公共配置：16 阵元 ULA、间距 0.5λ、两个信源 ±10°、不相干、SNR=10 dB、200 快拍、每点 500 次、种子 20261116；成功门限 1°；使用共同随机数比较算法。每种误差单独开启，按试验随机实现。

| 场景 | 扫描值 | 默认排行榜位置 |
|---|---|---|
| 不相干 SNR | −10, −5, 0, 5, 10, 15, 20 dB | 0 dB 的 RMSE |
| 快拍数 | 8, 16, 32, 64, 128, 200, 500 | 16 快拍的 RMSE |
| 双源角度间隔（中心 0°） | 1, 2, 3, 4, 6, 8, 10° | 4° 的分辨概率 |
| 相干信源 SNR | −10, −5, 0, 5, 10, 15, 20 dB | 10 dB 的 RMSE |
| 幅度误差 σg（相位误差固定 0） | 0, .025, .05, .1, .2 | .1 的 RMSE |
| 相位误差 σφ（幅度误差固定 0） | 0, 1, 3, 5, 10° | 5° 的 RMSE |
| 位置误差 σ | 0, .01, .025, .05, .1 λ | .05λ 的 RMSE |
| 互耦第一邻元系数幅度 | 0, .05, .1, .2, .3 | .2 的 RMSE |
| 未知坏阵元比例 | 0, .05, .1, .2, .3 | .1 的 RMSE |

需求方已批准上述方案（2026-11-16）。不修改原设计文档。

实现核查：阵元故障插件使用整数 `count`，16 阵元无法精确表示 5%、10%、20%、30%。建议发布场景使用故障数 `[0, 1, 2, 3, 5]`，明确显示实际比例 `[0, 6.25%, 12.5%, 18.75%, 31.25%]`，排行榜取 2 个故障阵元。互耦只设置第一邻元系数为 1∠0°，扫描 `scale` 得到表中幅度；不额外加入第二邻元互耦。
