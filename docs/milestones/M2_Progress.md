## Phase 1: 误差插件（✅ 已完成）

**标签**：`v0.1.0-m2p1`  
**完成时间**：2024年

### 完成内容

实现了按接口规范第 8.2 节设计的四类内置误差插件：

1. **位置误差** (`position`)
   - 阵元位置在指定轴上偏离标称位置
   - 参数：`sigma`（标准差，λ）、`axes`（x/xy/xyz）
   - 参考阵元（第 0 个）误差固定为 0
   - 作用阶段：`positions`

2. **幅相误差** (`gain_phase`)
   - 增益和相位独立偏离标称值
   - 参数：`sigma_g`（增益）、`sigma_phi_deg`（相位，度）
   - 支持固定增益/相位（`fixed_gains`、`fixed_phases_deg`）
   - 参考阵元 g=1、φ=0
   - 作用阶段：`manifold`

3. **互耦误差** (`mutual_coupling`)
   - 对称 Toeplitz 互耦矩阵建模阵元间耦合
   - 参数：`coefficients`（复数列表 c₁, c₂, ...）、`scale`（强度因子）
   - 确定性误差（`sample` 返回空字典）
   - 作用阶段：`manifold`

4. **阵元故障** (`element_failure`)
   - 指定或随机选择故障阵元
   - 参数：`indices`、`count`、`mode`（zero/noise_only）、`known`
   - 两种模式对应不同阶段（通过 `stage_for` 动态选择）
   - 排除第 0 个参考阵元
   - 作用阶段：`signal`（noise_only）或 `output`（zero）

### 设计特点

- ✅ **sample/apply 分离**：强度参数只在 `apply` 中使用，保证误差"形状"固定
- ✅ **describe 方法**：返回人类可读的实际误差值
- ✅ **known_mask**：支持算法已知故障位置
- ✅ **动态阶段选择**：`stage_for` 方法（element_failure）
