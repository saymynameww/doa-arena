# 统一搜索范围预览（2026-11-20）

## 1. 完成内容

保留完整角度坐标和真实信源，统一搜索范围浅蓝、范围外置灰，编辑起止角度后立即更新。固定信源越界和随机角度范围越界分别提示，边界包含在搜索范围内。修复随机角度没有固定角度数组时扇区不显示的问题。图注明确独立网格和无网格算法的适用边界。无效输入不绘制误导扇区。设计文档 v0.8 及 HTML 原型同步。

## 2. 怎么验收

新建实验，将统一范围改为 −5°～5°，观察浅蓝区域缩小，原来的范围外信源仍显示并列出提示。恢复 −90°～90°，提示消失。随机角度模式保留黑色虚线范围并提示潜在越界。清空或反转搜索起止角度应显示无效提示，不出现畸形扇区。
