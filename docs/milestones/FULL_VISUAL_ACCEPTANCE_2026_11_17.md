新增/扩展回归覆盖：概率百分数、真实扫描横轴、单次线性谱和无谱标记、分信源分布、结果表与图表一致、按指标语义比较、随机角度及故障预览、模板类型与工作目录登记、运行模式与结果可用性、取消记录空百分比、NPZ 并发原子替换、中断恢复进度。

三个关键缺陷均先用失败测试复现再修复：

1. NPZ 读取在逐试验循环中重复解码整块数组、持续持有 Windows 文件句柄，导致检查点替换 PermissionError。现在先读取内存快照释放磁盘句柄，每个数组只解码一次；回归测试在解码时实际替换原文件。
2. 旧取消记录 `percent=null` 与 API 的数值合同不兼容，导致整个历史列表 500。统一响应进度归一化，兼容旧文件，不重写用户数据。
3. 中断整理将 status.json 改为仅含状态，刷新后进度丢失。现在保留既有状态并写回真实完成次数与总数。

MATLAB 原内部可执行文件启动在完整回归中多次出现 180 秒无输出超时，单独重试曾通过；这些失败不能解释为数值断言失败，也不能证明超时根因已完全定位。测试已改用公开 `matlab` 启动入口，Windows 添加 `-wait`，并增加末尾成功文件，保证实际执行完所有断言。180 秒超时及数值断言保持不变，超时清理仅作用于本测试派生的进程。依据：[MathWorks Windows 启动文档](https://www.mathworks.com/help/matlab/ref/matlabwindows.html)。修改后独立导出测试 4 passed（9.74 s），最终标准顺序全套结果见本节开头。
