## 2. 怎么验收

```powershell
python -m pytest tests/integration/test_datasets.py tests/integration/test_models.py tests/integration/test_learning_workflow.py -q
python scripts/create_learning_example.py D:/10_Projects/DOA_Estimation/Projects/arena-cnn-example
cd D:/10_Projects/DOA_Estimation/Projects/arena-cnn-example
python train.py --samples 512 --epochs 2
```

训练示例必须在竞技场仓库外。Linux 对应命令相同，目录换为独立课题路径。先使用云环境已有 PyTorch，再安装 `packages/arena_api` 和 `packages/arena` 核心包；核心依赖不包含 torch，CI 检查安装前后 torch 版本一致。

数据集 CLI：`arena dataset generate dataset.yaml --out data/train --range 0:10000`。中断后重跑会核验分片并补齐缺失区间。多个进程可以生成不同输出目录；同一输出目录的写入由文件锁串行保护。

在设置中注册课题 `algorithms`，算法库导入模型包，新建实验选择模型并运行。超出训练范围仅警告，模型阵列不匹配或权重损坏拒绝推理。
