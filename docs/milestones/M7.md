## 2. 怎么验收

```powershell
python -m pytest tests/integration/test_benchmark.py -q
arena benchmark list --workspace arena_ws
arena benchmark run --workspace arena_ws --suite doa-basic --version 1.0 --algorithms algorithms.json
arena benchmark leaderboard --workspace arena_ws --suite doa-basic --version 1.0 --column 0
```

`algorithms.json` 是与实验配置相同的算法实例列表。网页：新建实验中配置算法，切到排行榜，选择场景集与版本并运行；点击不同列切换排名，点击数值进入对应结果；自定义场景集使用 JSON 导入。

实际 HTTP 验收：独立工作目录 `arena_ws/m6_m7_acceptance` 中的 `acceptance-500@1.0`（正式发布前的验收副本），评测 `20261116-233433_bench_ea7fc17c`，8 个场景、48 个扫描点、每点 500 次，共 24,000 次共同数据试验、48,000 次算法估计。MUSIC+FBSS 与 TLS-ESPRIT 全部完成，所有点的算法异常计数为 0；两行排行榜均无缺失项，16 个结果链接齐全。此结果不冒充尚未冻结的 9 场景 doa-basic 1.0。
