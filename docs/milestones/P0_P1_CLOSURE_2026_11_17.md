## 2. 怎么验收

用户入口与安装见 [安装使用说明](../../packages/arena/README.md)。以下命令在仓库根目录执行：

```powershell
$env:PYTHONUTF8='1'
$env:MKL_THREADING_LAYER='SEQUENTIAL'
& D:/10_Projects/DOA_Estimation/.venvs/arena-gpu/Scripts/python.exe -m pytest -q
& D:/10_Projects/DOA_Estimation/.venvs/arena-learning/Scripts/python.exe -m pytest -q
python -m mypy packages
python scripts/generate_api_types.py --check
python scripts/build_release.py
Set-Location frontend
npm test
npm run lint
npm run build
```

性能复测：开发服务打开 `http://127.0.0.1:3000/?uiAudit=1`，完成页面切换/参数修改，控制台读取 `ARENA_UI_AUDIT`。仅开发构建启用，生产 JS 已检查不包含该标记。计时从真实事件 `timeStamp` 到下一帧绘制后任务，包含页面渲染和调度开销，不含自动化工具往返。只记录控件标签/事件/耗时，不记录输入值。

**响应与异步加载分开**：0.5 秒指标用于交互反馈和可响应界面；首次 Schema/环境探测、历史数据读取、报告计算异步执行并显示等待状态，不宣称所有后台结果在 0.5 秒内生成。工具往返曾测得 579 ms，原始记录保留；没有删去该值冒充页面测量。改用页面内计时是消除工具开销，不调整 500 ms 门限。47 次真实事件最大 128.2 ms；不是对无限插件组合的最坏上界证明。

PDF 验收：内置浏览器 `window.print()` 调用超时，未打开原生打印对话框。需求方已明确接受“内置浏览器核对 HTML + 离线排版生成并逐页检查 PDF”。WeasyPrint 是本机文件排版工具，没有通过其他浏览器或 CDP 绕行；没有将原生打印接口标成通过。临时工具放在 `arena_ws/p01_closure`，未加入产品依赖或基础/CPU/GPU 环境。依据：[WeasyPrint 官方 Windows 说明](https://doc.courtbouillon.org/weasyprint/latest/first_steps.html#windows)。

最终 PDF：`arena_ws/p01_closure/final_report.pdf`，9 页、89697 B，SHA256 `518f5d6b6f2a4b7e9312d361656b641f31a8dc9104841dd72b1738b1072d4965`。源 HTML 同目录。最终页脚使用实际 `arena.__version__`，修正此前写死的 v0.3.0。
