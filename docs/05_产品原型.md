# DOA估计研究室 · 算法竞技场（Arena）产品原型

| 项目 | 内容 |
|---|---|
| 文档版本 | v0.1（初稿，待评审） |
| 日期 | 2026-10-29 |
| 原型文件 | `docs/prototype/index.html`（单文件，浏览器直接打开，无外部依赖） |
| 依据 | 《01_需求规格说明书》v0.8 第 6、7 章，《02_系统架构设计》v0.6 第 7 章，《04_数据格式规范》v0.2 |
| 读者 | 需求方（评审界面）、前端开发者 |

本文档说明每个页面**有什么、怎么交互、对应哪条需求**。原型是中等保真：布局、控件、文字、交互流程接近真实界面，配色和细节以 Ant Design 默认风格为准，不追求最终视觉效果。原型中的数据全是假数据。

**原型与正式实现的关系：**
- 原型用手写 HTML 表单表示算法参数；正式界面中，算法、阵列、误差的参数表单**全部由后端 JSON Schema 自动生成**（架构 7.2 节），前端不写任何算法专用代码。原型中的参数只是“生成后长什么样”的示例。
- 原型用 SVG 手绘曲线；正式界面使用后端返回的 Plotly 图表（架构 ADR-05）。
- 原型中的“运行”是定时器模拟；正式界面通过 SSE 接收进度（架构 6.3 节）。

## 2. 实验配置页（主页面）

```
┌ 新建实验 [实验名称______] [从模板加载▾] [保存为模板] [导出 JSON / 脚本] ┐
├──────────────── 场景 + 预览 ──────────┬────────── 算法 ──────────────────┤
│ ▾ 阵列：类型、M、d、载频（仅显示）     │ [+ 添加算法 ▾]                   │
│ ▾ 信源：K（固定/随机）、角度设置、     │ ☑ MUSIC        参数…   ⚠ 提示   │
│        SNR、相关性、快拍数             │ ☑ MUSIC+FBSS   参数…            │
│ ▾ 阵列误差：四类，各自开关、           │ ☑ TLS-ESPRIT   参数…            │
│        固定/每次随机、参数             │ ☑ B（外部）    模型包、设备 ⚠   │
│ 随机种子 [12345] [随机]                │ ☐ Root-MUSIC（置灰，悬停说明）  │
│ ▾ 场景预览：阵元与信源方向示意         │                                  │
├───────────────────────────────────────┴──────────────────────────────────┤
│ 实验方式 ○单次 ○蒙特卡罗 ●参数扫描  扫描变量▾ 取值 每点试验 公共随机数 指标 │
│ 共 N 次估计，预计 X 秒   [1 条警告]                         [运行实验] │
└──────────────────────────────────────────────────────────────────────┘
```

| 元素 | 行为 | 需求 |
|---|---|---|
| 场景分组 | 可折叠；字段由所选阵列插件、误差插件的 Schema 生成 | FR-SCN-01~08、12 |
| 角度设置 | 下拉切换“固定角度 / 范围内随机 / 中心 ± 间隔/2”，切换后只显示对应输入项 | FR-SCN-04，数据格式 3.3 |
| 信源数 K | “固定 / 随机”；随机时输入取值集合 | FR-SCN-03 |
| 相关性 | 选“部分相关”时出现幅度 + 相位两个输入框 | FR-SCN-06 |
| 即时校验 | 输入时按 300 ms 防抖调用后端校验；错误显示在字段下方（红色），并禁用“运行实验”。原型演示：把 K 改成 ≥ M | NFR-31，数据格式 3.9 |
| 场景预览 | 阵元位置（含误差后的位置，故障阵元红色）和信源方向，参数改变后即时重绘 | FR-SCN-11 |
| 添加算法 | 下拉列出已注册算法，分“内置 / 外部”两组；同一算法可添加多次 | FR-ALG-03 |
| 算法实例卡片 | 勾选框（启用 / 停用）、可编辑显示名、来源标签、参数表单（由 Schema 生成）、提示标签 | FR-ALG-02~05 |
| 算法提示 | 黄色：插件 `check()` 的警告（如相干信源未平滑）、训练范围、未提交修改；置灰：能力不满足，悬停显示原因 | FR-ALG-05、FR-GEN-06、FR-ALG-01c |
| 实验方式栏 | 三种方式单选；参数扫描时显示扫描变量下拉（列出常用路径，数据格式 3.6 节）、取值（支持 `起:步:止` 或列表）、试验次数 | FR-EXP-01、03 |
| 运行次数估计 | 实时显示总估计次数和预计耗时；超过阈值时变为黄色提醒 | FR-EXP-04 |
| 警告标签 | 点击展开全部警告；警告不阻止运行 | 数据格式 3.9 |
| 运行实验 | 提交后跳转到运行与结果页 | FR-EXP-05 |
| 导出 JSON / 脚本 | 下载当前配置的 JSON，或生成等价的 Python 脚本 | FR-API-06 |

编辑中的配置自动保存到浏览器本地存储，刷新页面不丢失（架构 7.3 节）。

## 3. 运行与结果页

同一页面按实验状态切换内容（架构 7.1 节）：运行中显示进度并逐点画曲线，结束后显示完整结果。

| 区域 | 内容与行为 | 需求 |
|---|---|---|
| 标题栏 | 实验名、状态标签（排队 / 运行中 / 完成 / 已中止 / 失败 / 中断）、实验 ID、运行模式；“中止”“复制并修改”“重新运行” | FR-EXP-06、FR-DAT-03/04 |
| 进度条 | 当前扫描点、完成百分比、预计剩余时间；SSE 推送 | FR-EXP-05 |
| 主图 | 指标下拉（RMSE + CRB / 成功率 / 分辨概率 / 耗时）；对数纵轴开关；样式预设（网页 / 论文单栏 / 论文双栏）。每完成一个扫描点增加一个点 | FR-RES-04~07、10 |
| 导出 | 图 PDF / SVG / PNG、`.mat`、CSV、LaTeX 表格、HTML 报告、导出为脚本；文件写入实验的 `exports/` 并下载 | FR-RES-07/08/11、FR-DAT-07 |
| 备注与标签 | 运行中也可编辑，写入 `notes.json` | FR-DAT-02 |
| 指标汇总表 | 选择扫描点；每算法一行：RMSE、sqrt(CRB)、成功率、耗时中位数、纳入统计试验数、出错数、状态；可排序、可复制；“修改指标参数并重新计算”不重跑实验 | FR-RES-02、数据格式 3.7 |
| 警告与错误 | 运行前和运行中的警告；错误按类型汇总，显示首次出现的位置和次数，可展开堆栈 | FR-ALG-09、FR-SYS-03，数据格式 4.6 |

单次实验时，主图换为空间谱叠加图（多算法谱、真值竖线、dB / 线性切换，FR-RES-01）；蒙特卡罗实验时，主图换为估计值散点 / 直方图（FR-RES-03）。原型只画了参数扫描的情况。

中止后，已完成的扫描点保留，状态为“已中止”。原型演示：运行后点击“中止”。

## 4. 历史实验页

| 元素 | 行为 | 需求 |
|---|---|---|
| 筛选栏 | 按名称 / 备注搜索；按算法、运行模式（Web / 脚本）、标签筛选 | FR-DAT-02 |
| 实验列表 | 勾选框、名称（★ 为星标）、时间、实验类型、算法、模式、状态、标签、操作 | FR-DAT-02 |
| 操作 | 查看、复制修改、重新运行、导出脚本、删除（二次确认，移入 `.trash/`）；“中断”状态的实验显示“整理部分结果” | FR-DAT-03~05，数据格式 4.6 |
| 对比选中实验 | 勾选两个以上扫描变量相同的实验后可用，进入多实验对比页 | FR-RES-09 |

脚本模式运行的实验与 Web 实验在同一列表中，刷新即可看到（FR-SYS-05）。

## 5. 多实验对比页

选择若干实验和同一指标，叠加曲线；图例为“实验名 / 算法”。扫描变量不同的实验不能放在一起，选择时置灰并说明原因（FR-RES-09）。

## 6. 算法库页

| 区域 | 内容 | 需求 |
|---|---|---|
| 算法列表 | 名称、id、类别、来源（内置 / 外部目录）、版本、Git commit 及“未提交修改”标记、适用条件 | FR-ALG-01、01c |
| 加载失败的插件 | 单独一行红色显示，可展开堆栈；不影响其他插件 | FR-ALG-01b |
| 刷新 | 重新扫描算法来源，修改外部算法代码后不需要重启 | 架构 6.1 |
| 模型包 | 工作目录 `models/` 中的模型：插件、阵列、训练条件、信号模型版本是否一致、训练平台；“导入模型包”导入目录或 zip | FR-ALG-14、FR-GEN-08 |

点击算法行，展开说明、参考文献和参数列表（由 Schema 生成）。

## 7. 模板页

列出场景模板和实验模板，标明来自“内置”还是“工作目录”。操作：用模板新建实验、编辑、复制、删除（内置模板只能复制）。需求 FR-SCN-10，数据格式 7.3 节。

## 8. 排行榜页（P1）

选择场景集及版本；表格每行一个算法，列由场景集的 `leaderboard` 定义（数据格式 7.4 节）；每个单元格可跳转到对应实验。“选择算法运行场景集”打开算法选择对话框后批量运行。需求 FR-BEN。

## 9. 设置页

| 区域 | 内容 | 需求 |
|---|---|---|
| 工作目录 | 当前工作目录、新建 / 添加 | FR-DAT-01b |
| 外部算法来源 | 分“工作目录层”和“全局层”两组列出；全局层可添加 / 删除目录 | FR-SYS-04，数据格式 2.2 |
| 运行环境 | Python、NumPy、PyTorch 版本，CUDA 是否可用，GPU 型号；默认推理设备 | FR-SYS-02、NFR-23 |

## 10. 典型流程在原型中的走法

| 需求第 7 章流程 | 走法 |
|---|---|
| 1 快速对比 | 实验配置 → 选“单次” → 勾选算法 → 运行实验 → 看空间谱 |
| 2 论文出图 | 实验配置 → 从模板加载 → 参数扫描 SNR → 运行 → 主图选“论文单栏”样式 → 导出 PDF |
| 3 误差鲁棒性 | 打开幅相误差、选“每次随机” → 扫描变量选 σ_φ → 运行 |
| 4 学习型算法评测 | 算法库导入模型包 → 实验配置添加 B、选模型包 → 运行 → 看训练范围提示 |
| 5 复现 | 历史实验 → 重新运行 |
| 6 接入新算法 | 在 `algorithms/` 下新建子目录写 `arena_plugin.py` → 算法库点刷新 |
| 7 脚本模式 | 脚本运行后 → 历史实验页刷新，模式为“脚本” → 查看 / 对比 / 导出 |
| 9 场景集 | 排行榜 → 选择算法运行场景集 |

## 11. 原型没有覆盖的内容

- 单次实验的空间谱图和蒙特卡罗的散点图（第 3 节已说明）。
- 添加算法的下拉菜单、模型包导入对话框、删除确认对话框、堆栈弹窗。
- 历史页的分页和排序。
- 二维扫描热力图（FR-EXP-09，P2）。

以上按 Ant Design 的常规组件实现即可，不需要单独设计。
